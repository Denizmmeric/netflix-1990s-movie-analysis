# Netflix Movies Analysis: The 1990s 🎬

## Project Overview
This project explores Netflix movie data to investigate trends in films released during the 1990s (1990–1999).
Using Python and Pandas, I performed exploratory data analysis (EDA) to examine movie durations and identify short action films.

## Objectives
The analysis focuses on two main questions:
1. What was the most frequently occurring movie duration during the 1990s?
2. How many action movies released in the 1990s were shorter than 90 minutes?
   
## Key Findings
- **Most frequent movie duration:** 94 minutes
- **Number of short action movies:** 7
- Short movies were defined as films with a duration of less than 90 minutes.
  
## Methodology
The analysis involved the following steps:
1. Loading the Netflix dataset using Pandas.
2. Exploring the dataset and examining its structure.
3. Filtering movies released between 1990 and 1999.
4. Identifying the most frequent movie duration using statistical methods.
5. Filtering action movies with durations below 90 minutes.
6. Counting the movies that met the specified conditions.
